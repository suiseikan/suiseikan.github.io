# 空手道剛柔流 翠政館 ホームページ

愛知県名古屋市中川区の空手道場「空手道剛柔流 翠政館」の公式サイト(試作)。

## 構成

- `index.html` / `style.css` / `script.js` — 本番トップページ(重厚・和モダン案)
- `cool-2-sporty/` — カッコイイ系②:格闘技イベント風
- `kids-1-clean/` — 子供向け①:元気ポップ(クリーン)
- `kids-2-craft/` — 子供向け②:元気ポップ(手描き工作風)
- `trust-1-parents/` — 保護者向け:あんしん・誠実
- `compare/` — 5案を見比べるための比較ページ
- `assets/images/` — ロゴ・代表者写真などの共有素材

## 技術

素のHTML / CSS / jQueryで実装。ビルド不要、静的ホスティングでそのまま公開可能。

## ローカルで見る

```bash
python -m http.server 8000
```

`http://localhost:8000/` を開く。
